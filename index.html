nest-control

nest-control is a private command-line tool that reads and adjusts the owner's own Google Nest thermostat through Google's Smart Device Management API.

It is used by one person on their own household devices. It is not offered to the public, has no user accounts, and is not available for download.

What it does

  • Reads the current temperature, humidity, and HVAC status
  • Sets the target temperature or heat/cool range
  • Changes the thermostat mode and Eco setting
